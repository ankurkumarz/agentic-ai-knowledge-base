# AI Coding Agents

## Concepts

* [AI Coding Agents](ai-coding-agents.md) - AI coding agents are purpose-built autonomous tools that read codebases, plan changes, execute them using real development tools (terminal, editor, browser), and iterate on the results
* [Claude Code](claude-code.md) - Claude Code is Anthropic's terminal-based AI coding agent that operates directly in the developer's environment with full filesystem and shell access.
