# Security Frameworks

## Concepts

* [Agentic AI Security](Readme.md) - This section provides comprehensive coverage of security frameworks, standards, and best practices for building secure agentic AI systems
* [Microsoft Agent Governance Toolkit](agent-governance-toolkit.md) - The **Agent Governance Toolkit (AGT)** is an open-source, MIT-licensed runtime governance framework from Microsoft that enforces deterministic policy over autonomous AI agents
* [Agent Sandboxing](agent-sandboxing.md) - Sandboxing is the practice of running agent-invoked code or tools in an isolated execution environment that constrains what resources the process can access
* [Agentic AI Red Teaming Guide (CSA)](agentic-ai-red-teaming-guide.md) - Red teaming is the practice of simulating real-world adversarial attacks against a system to uncover exploitable weaknesses before malicious actors do
* [Anthropic Sandbox Runtime](anthropic-sandbox-runtime.md) - The **Anthropic Sandbox Runtime** (`srt`) is a lightweight, OS-level sandboxing tool that enforces filesystem and network restrictions on arbitrary processes without requiring a container
* [Google SAIF Framework](google-saif.md) - Google's Secure AI Framework (SAIF) for implementing security in AI systems
* [NIST AI RMF (Risk Management Framework)](nist-ai-rmf.md) - NIST's AI Risk Management Framework for managing risks in AI systems
