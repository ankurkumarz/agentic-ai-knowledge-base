# Production Best Practices

## Concepts

* [Production Best Practices & Guidelines](README.md) - A consolidated reference for teams moving agentic AI systems from prototype to production
* [Context Engineering](context-engineering.md) - Context engineering is the discipline of deciding what information goes into an agent's context window, when, and in what form
* [Cost Management for Agentic AI](cost-management.md) - Cost management is a first-class production concern for agentic AI systems
* [Deployment](deployment.md) - Deploying agentic AI systems requires practices that go beyond standard software deployment
* [Observability](observability.md) - Observability for agentic AI goes beyond traditional APM
* [Agent Security](security.md) - Agentic AI systems introduce security risks that don't exist in traditional software
* [State & Memory Management](state-memory.md) - Effective memory management determines whether an agent feels like a persistent, intelligent system or a stateless chatbot
* [Agent Testing & Evaluations](testing-evaluations.md) - Evaluating agentic AI systems is fundamentally different from traditional software testing
